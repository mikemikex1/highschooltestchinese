學測國文30課 GitHub Pages 發布目錄

本資料夾可直接設定為 GitHub Pages 的 /docs 發布來源。
首頁：index.html

本版為純靜態網站，不需要 Node、後端或網路 API。教材、JavaScript 與樣式已由最終離線版同步；官方 PDF 位於 PDFs/。

本機預覽：
可用任一靜態檔案伺服器開啟 docs/，或直接以瀏覽器開啟 docs/index.html。Hash 路由使用 #lesson-15-view-03 等格式。

部署後網址格式：
https://USERNAME.github.io/REPOSITORY/

請勿移動 PDFs/，否則官方資料連結會失效。
